## Git 日常四条命令

```bash
git add .                          # 把改动放进暂存区
git commit -m "说明这次改了什么"    # 拍快照
git push                           # 推到 GitHub
git status                         # 看现在有什么没提交（最常用）
```

查看提交历史：

```bash
git log --oneline
```

## 查 PATH 的正确方法

`$env:Path` 只是当前进程的快照，改完 PATH 不重开终端看不到。真实值要看注册表：

```powershell
[Environment]::GetEnvironmentVariable('Path','Machine')
[Environment]::GetEnvironmentVariable('Path','User')
```
