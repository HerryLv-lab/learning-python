# learning-python

从 C 转 Python 的练习仓库，目标是 2027 年暑假拿到 AI Agent 方向的实习。

完整周计划见同目录外的 `AI-Agent实习周计划.md`。

## 目录

```
week01/     第一周：用 Python 重写 3 个写过的 C 程序
leetcode/   刷题代码，文件名用题号命名，如 0001_two_sum.py
notes/      踩坑记录、命令备忘
```

## 规则

1. **每周至少一次 commit**，提交信息写清楚改了什么，不写 update。
2. 每周日复盘三行：做了什么 / 卡在哪 / 下周改什么。
3. 代码跑通了再提交，提交前先自己跑一遍。
