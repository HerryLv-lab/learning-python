## 练习 3：命令行小计算器（约 30 分钟）

**目标**：循环读入算式，算出结果，输入 `quit` 退出。

```
请输入算式：3 + 5
= 8
请输入算式：10 / 0
除数不能为 0
请输入算式：quit
再见
```

**要求**：

1. 支持 `+ - * /` 四种运算
2. 用 `while True` 循环，输入 `quit` 时 `break`
3. 除以 0 时提示“除数不能为 0”，不能让程序崩掉
4. 输入格式不对（比如只输了一个数字、或者 `abc`）时，提示“格式不对”，继续循环

**会用到的语法**：

| 语法 | 作用 |
|---|---|
| `while True:` + `break` | 无限循环，条件满足再退出 |
| `"3 + 5".split()` | 切成 `['3', '+', '5']` |
| `float("3")` | 字符串转数字 |
| `if 运算符 == "+":` | 分支判断 |

**拆解建议**：先只支持加法，跑通循环和退出；再加减法；最后统一处理四个运算符和异常。

## LeetCode 1：两数之和（约 20 分钟）

**题目**：给一个整数数组 `nums` 和一个目标值 `target`，找出数组里**两个**数，使它们的和等于 `target`，返回它们的下标。

```python
nums = [2, 7, 11, 15]
target = 9
# 期望输出 [0, 1]，因为 nums[0] + nums[1] = 2 + 7 = 9
```

**要求**：不打双层 `for` 循环（那是 O(n²)），用**字典**做一次遍历，做到 O(n)。

**思路提示**：遍历每个数字 `x` 时，你需要的搭档是 `target - x`。把“见过的数字 → 它的下标”存进字典，每读一个新数就先查搭档在不在里面。

这就是你在词频统计里已经用过的那个模式：`if 某东西 in 字典` / `字典[键] = 值`。只是这次键是数字，值是下标。

**文件要求**：放在 `../leetcode/0001_two_sum.py`，顶部写三行注释：

```python
# 思路：一次遍历，用字典存「值 -> 下标」，查 target - x 是否已出现
# 复杂度：O(n) 时间 / O(n) 空间
# 易错：不能把自己和自己配对，所以先查后存
```

## 附：C 和 Python 的差异对照

| C 里要手写 | Python 里是什么 |
|---|---|
| `malloc` / `free` | 不用管，自动回收 |
| 数组 + 长度变量 | `list`，自带 `append` / `len` |
| 手写哈希表 | `dict` |
| `strlen` / `strcpy` / `strcmp` | `len()` / `=` / `==` |
| `printf("%d")` | f-string：`f"{x}"` |
| 编译再运行 | 直接 `python x.py` |
| `fopen` / `fclose` | `with open(...) as f:` |
